classes_ and predict_proba() are zipped into a semantic probability dictionary, so downstream code reads by class name rather than a brittle numerical index:

classes = pipeline.classes_.tolist() probs = pipeline.predict_proba([text])[0] return dict(zip(classes, probs)) → {"Financial": 0.91, "Operational": 0.09}
04 — Decision Gate
Top-class confidence p₁ ≥ threshold
Top-vs-runner-up margin p₁ − p₂ ≥ margin
Metadata agreement predicted == metadata
PASS = Confidence ∧ Margin ∧ Metadata Agreement

Confidence and margin thresholds are configurable, defaulting to approximately 0.70 and 0.20.

The gate is non-short-circuiting: every check runs, and all failures are collected rather than stopping at the first.

failures = [] if p1 < min_confidence: failures.append("LOW_CONFIDENCE") if margin < min_margin: failures.append("SMALL_PREDICTION_MARGIN") if not metadata_match: failures.append("METADATA_CONFLICT")
